今天算是把这个站从零拧到了现在这个样子。睡前觉得该记一笔，不然过两天肯定忘。

## 从空仓库到能打开

凌晨零点多从 `init blog` 开始。先把 GitHub Pages 的部署流程搭起来，不然改完只能本地看。接着上了 Giscus 评论和点赞，那时候还觉得评论区有个能说话的地方就够了。

真正开始有感觉是改成「记忆终端」那套视觉之后。先是换掉原来的剪贴画，改用渐变主视觉；后来又换成无畏契约官方壁纸当头图和封面，整站才有点我自己的味道。导航图标也从 emoji 换成了干净的 SVG，细节上顺眼很多。

功能那一段是集中补的。全文搜索和 RSS 先上，暗色模式、目录、阅读进度跟上，字数和预计阅读时间也算了进去，系列连载也开了。补完之后它才像一个能长期用的博客，之前不过是首页的壳子。

域名这块踩过坑。一开始想用 GitHub Actions 直接发，后来为了稳妥改成 `docs/` 目录部署，CNAME 也配好了，现在是 `zixuann.top`。中途还出过一次 CNAME 丢掉的事故，构建输出里重新加回去才好。

## 站名、头像和一些零碎

后面几笔都是「看起来小、改起来烦」的活。站名从 zixuann 换成归舸，页脚叫「归舸的大窝」。头像从默认图换成自己的，品牌位和侧栏资料卡都跟着换了。年龄也改成了 16。

访问统计原来用的不蒜子，后来换成了 Abacus 计数。这个改动不大，但加载上干净一点。

首页那句副标题改过好几次。最后定成「打瓦、想东想西——慢慢记下来」。原来那句「正在同步生活、技术、灵感与未命名的片段」太像说明书了，不像我。写代码这仨字后来也去掉了，副标题就留打瓦和想东想西，更像平时说话。

## 友链，删掉

友链页整页删了，没保留。导航、侧栏、站点地图、关于页里那句「欢迎加友链」，一起清干净。现在连 `friends.html` 都会 404。

删的时候踩了一个挺有意思的坑。本地 `dist` 明明已经是新的，线上 `friends.html` 还是 200。查下来是 GitHub Pages 实际在吃 `docs/` 目录，而 `docs` 那份还留着旧页面。把 `docs` 同步成无友链版本再推，线上才真正没了。这种「改了 A，生效的是 B」的情况，今天遇到了不止一次。

## 阅读时长和评论

「归舸的大窝」那篇阅读时长原来显示 1 分钟，我给改成了 18 分钟。字数没变，时长是单独写的，后来在 frontmatter 里加了 `minutes` 字段，想写多少写多少，不用再改构建脚本。

评论区也换了。从 Giscus 换成 Waline，支持 QQ 邮箱登录，数据存在 GitHub 上。客户端后来从 jsDelivr 拉，国内访问快一些。

## 一点感想

今天大概推了二十多次，每一笔都不大，叠起来就很多。中间有几段时间全在处理部署和缓存：本地改好了，网页打开还是旧的；推上去了，Actions 跑完，还要再等一会儿；有时候是浏览器缓存，Ctrl+F5 才看见新东西。

也碰到过 git 身份没配、本地分支叫 master 远端叫 main 这种事。好在最后都通了。

写博客这件事，花在写内容上的时间，今天其实不算多。大部分时候是在搭架子、调样式、修部署。不过这些活干完，以后写东西应该会顺手一点。架子稳了，人才有心思往里填。

就先记到这里。明天应该继续写内容，少折腾一点界面。
